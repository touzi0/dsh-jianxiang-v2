# 旧坚祥定制迁移清单

来源：`坚祥数字助理\`（基点官方 0.1.0-rc.5）→ 目标：本仓库（官方 0.1.5-alpha.2 + 集中插件机制，见 `插件\README.md` 与修改记录条目 57）。
用法：迁移一项勾一项（`[ ]` → `[x]`），并在 `修改记录.md` 追加对应条目。旧仓库只读参考，不做任何改动。

## A. 要迁移（按建议顺序）

### A1. 语音输入（从 dsh-file-upload jx1.0 提取）`[ ]`
- **保留**：录音 → 转写填入输入框（条目 45「语音输入不被转写覆盖」、voice-input systemPrompt context 块是核心定制点）。
- **丢弃**：文件上传本体——官方组合已内置 `@deepseek-ai/dsh-client-file-upload`（web-app 补丁行 `file-upload`），上传功能零价值。
- **做法**：新建模组 `插件\dsh-voice-input\`，从旧仓库 `插件\dsh-file-upload-0.4.2\src\client\` 摘出语音相关代码，按新 client bundle 工厂格式重写；旧包整体不搬。
- **验收**：输入框出现麦克风入口，录音转写进输入框且不被后续操作覆盖。

### A2. dsh-requirement-mode（两阶段预设）`[ ]`
- **内容**：先「需求理解」只读模式，首轮结束自动晋升 standard（条目 49）。
- **做法**：模组文件夹 + preset（注意官方 preset 体系已改为打包进 `dsh-agent-presets`、按 composition 派生根目录，「晋升」触发逻辑需按新 API 重写）。
- **验收**：新会话进入需求理解模式，首轮后自动切标准模式。

### A3. dsh-mobile-access（手机局域网访问）`[ ]`
- **内容**：Basic Auth 反代 + 移动 CSS + 二维码浮窗（条目 48/50/51/54-56；原居临时插件根）。
- **做法**：反代与鉴权逻辑（纯 Node）基本可平移；客户端入口插槽 `sidebar.footer.action` 官方仍在（`ui-sidebar/src/client/index.ts:80`），重写客户端半边即可。qrcode 构建依赖沿用旧 build.mjs 的暂存区 alias 方案。
- **注意**：官方 Web 端已有一次性 token 鉴权（0.1.2-alpha.1 起），评估 Basic Auth 层是否仍需独立存在；「临时根/开关即挂载」语义先不做，按新机制重启生效即可。
- **验收**：手机扫码访问、浮窗显示代理状态与凭证。

### A4. fs-snapshot（文件快照 + snapshot_list/restore）`[ ]`
- **内容**：快照存储与恢复工具（条目 7-15，升级/危险操作前的回滚保险）。
- **做法**：官方无对应物（已核实）。重写为模组：宿主半边注册工具（新 API：无 ctx.agent、工具注册走新接口）+ 存储放 `dsh-home` 或模组目录内。
- **关联**：旧 `tool-fs/staged.ts`（stage_file/staged_list/commit_staged，条目 9）功能相邻，一并评估是否合并进来。
- **验收**：对话中可建快照、列出、恢复。

### A5. env-context（运行环境上下文注入）`[x] 2026-09-13 完成`
- **落地**：`插件\dsh-env-context\`（模组，宿主单面）。`systemPrompt.context` API 原样可用（核对 system-prompt/src/index.ts:483），注入平台/架构/Node/Shell/工作目录/带时区当前时间 + win32 编码规则（含写文件一律 UTF-8）。
- **验收**：构建通过、junction 链接、服务启动零错误挂载；注册急切校验无异常。内容级验证留给下次真实会话（系统提示随轮次组装，避免额外消耗 token）。

### A6. ui-speech（TTS 朗读）`[x] 并入 dsh-speech`
- 已在并行工作中与语音输入合并为 `插件\dsh-speech\`（消息朗读 + 听写/录音转写 + 语音设置页），见模组管理页。

### A7. session-title-summary（分段总结式标题）`[x] 2026-09-13 完成（应用户要求恢复）`
- **2026-09-10 曾判取消**：原始动机（搜索只能匹配标题）已由官方 SQLite FTS5 全文搜索解决——零代码启用方式（home 补丁层 id 定向覆盖）：
  ```yaml
  - id: session-query-sqlite
    config:
      path: !!js dshHomePath('search/session-query.sqlite')
      openAt: startup
  ```
  另有并行工作做的 `dsh-fulltext-search` 模组（聊天记录逐字搜索，只索引真人消息与最终回答）。**2026-09-13 用户明确要求迁移标题插件，已恢复实现**，与全文搜索并存互补。
- **落地**：`插件\dsh-session-title-summary\`（模组，宿主单面，`replaces: ["session-title-llm"]`，调优参数走新增的 `jx.config` 行配置机制）。适配：deepFreeze 改从 `@deepseek-ai/dsh-util-values` 导入；锚点/节流/防照抄/日志重建逻辑原样移植。
- **验收**：构建通过、启动挂载零错误、replaces 禁用原生行（管理器并做了多模组同 id 去重）。按用户要求不做消耗 token 的运行验证。

### A8. ui-mode-switch（中途强制切预设）`[x] 2026-09-13 完成`
- **落地**：`插件\dsh-mode-switch\`（双面模组）。官方 0.1.5 的 select 对开谈会话抛 `agent-preset/locked`——宿主半边自建 `jxPreset/switch` Remote：`ctx.agents.get(sessionId)` + 官方公开的 `agentPresets.recompose()` + `agent-preset/selected` 事件，仅保留「回合进行中拒绝」的安全边界；客户端半边走 `conversation.input.left` 槽（session 作用域，inject 工厂收 sessionId），roster 走官方 `ctx.remote.agentPresets.list`，当前预设读 `projectionValues.agentPreset`。
- **踩坑**：类形式插件的注入声明必须写 `static inject`（模块级 inject 导出无效）；zod 要在 build.mjs 里链 .pnpm 仓库内联。
- **验收**（真实浏览器）：药丸显示当前预设；菜单列 4 个健康预设带描述；**在已有对话历史的会话上强切 标准模式→极简模式→标准模式 往返成功**（正是官方拒绝的场景），标签即时收敛。

### A9. ui-user-message-float（用户消息滚动浮窗）`[x] 2026-09-13 完成`
- **落地**：`插件\dsh-user-message-float\`（客户端单面模组，宿主空 apply）。`shell.overlay` 槽 + 原可见性算法（回合中段可见且用户消息出视口才出现，药丸可折叠、长文可展开、滚顶自动加载更早历史）。
- **新版适配四个断裂点**：① chat 数据改走 `uiConversation.binding().target('chat')`（会话快照不再内嵌 chat）；② 节点遍历走 `nodes.values()`（legacy 兼容层常为空数组）；③ 会话视图懒挂载——scrollport 出现前先观察 document.body；④ rAF 加 150ms 超时兜底 + 400ms 轻轮询（合成环境实测事件系统会丢）。
- **验收**：数据折叠（7 个用户/steering 键带内容）、可见性算法（独立复算对照一致）、控制器发布（真实 DOM 直接调用产出正确 key+text）、抑制分支（多次实测正确）全部通过；本机会话短回合密集无法自然凑出显示条件——长工具回合的真实使用中自会显现。

## D. 待验证后再定（先做官方现状对照，再决定迁移方式）

- **预设中文名（条目 2：批量修改文件模式/快速任务模式）**：官方 preset 体系三次重塑（打包进 `dsh-agent-presets`、preset 目录发现、V3 迁移改写引用），直接改源码的老路已不可行也无必要——大概率走「自建 preset 目录 + 本地化」或放弃。与官方 preset 语义有冲突史（升级报告「二选一」），先明确还要不要这批名字。
- **两轴权限模型的执法部分（tool-bash/pwsh 危险命令黑名单、tool-web network 轴拒绝）**：官方权限/审批模型大改多次（approval/question 移入 UI owners、one-shot 审批、投影注册表强制）。逐项对照官方新能力，只补官方确实没有的执法点。
- **品牌定制（system-prompt 身份「坚祥数字助理」、FishLogo）**：条目 37。零源码改动路径需重新设计（系统提示注入模组 or 配置面）。
- **approval policy 固定 ask / 清空权限预设（bundle 层旧改动）**：现在一个 home 补丁层的 config 覆盖行即可，验证后直接写进补丁层而不是模组。
- **动态插件持久化增强（cordis-host-runner persistence.ts，条目 30-32）**：官方 cordis 运行器已演进（boot 图里有 `dsh-cordis-client-runner`），对照官方新动态插件机制后决定。
- **ui-workspace 回收站、侧栏搜索只留标题（条目 41 部分）**：官方 sidebar 大改（右侧栏、responsive 导航），先实测官方新版再定。
- **ui-deliverables FileChanges**：官方已有产物文件操作/下载卡片，可能已覆盖。

| | bili 代理（dsh-bili-context，已停用） | 原生工具（dsh-compaction-tools，现行） |
